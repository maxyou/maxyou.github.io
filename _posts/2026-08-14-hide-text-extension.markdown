HideText has launched a lightweight browser extension supporting Chrome, Edge, and Firefox. This extension allows you to quickly and easily generate and insert hidden text links, as well as view hidden text directly without leaving the current page.

### Installation

1. Open your browser's extension store (Chrome Web Store, Microsoft Edge Add-ons, or Firefox Add-ons).
2. Search for "Hide Text" and install the extension published by the project.

### Usage

1. Click on any text input field or comment box on a webpage.
2. Click the HideText extension icon in your browser's toolbar.
3. Enter the text you wish to hide.
4. Click "Insert" to place the link into the current input field.
5. Once the generated link is posted, simply hover your mouse over it to reveal the hidden text content.

### Future Plans

We plan to make the browser extension the primary way to use HideText, as it offers the simplest and most convenient user experience.
